# 双色球研究工作台

本地中文页面，用真实历史开奖数据做概率研究：管理数据、比较概率模型、按时间训练验证，以及保存开奖前的预测记录。运行环境为 **Node.js 22 或更新版本**，没有第三方运行依赖，不需要安装 Python 或下载大模型。

## 启动

双击本目录的 `启动工作台.cmd`，等待几秒，默认浏览器会自动打开 <http://127.0.0.1:3210/>。请保留启动窗口；重复双击会打开已运行的工作台。如果浏览器没有自动打开，也可手动访问该网址。启动失败时窗口会保留错误提示。

也可在项目目录执行以下命令，自动启动并打开页面：

```powershell
node scripts/start.mjs
```

只启动服务、不自动打开浏览器：

```powershell
node server.mjs
```

关闭服务窗口即可停止。数据和记录会保存在本地，下次启动仍可查看。如端口被占用，可在 PowerShell 中执行 `$env:PORT=3211` 后启动，再访问对应端口。服务仅监听 `127.0.0.1`。

## 当前数据

初始数据来自中国福利彩票发行管理中心公开开奖接口，获取于 **2026-10-30**，共 **2,082 期**，覆盖 **2013001—2026124**（最新日期 2026-10-29）。最近 100 期与上海福彩公开数据逐期交叉核对一致。

这是该官方接口提供的范围，**不是从 2003 年上市起的全部历史**。没有用模拟数据补齐空缺。页面会显示覆盖、来源、获取时间和缺期提示。

- 中国福彩接口：<https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice>
- 上海福彩交叉核验：<https://appsh.swlc.net.cn/shfcoc_datachart/datachart/ssq/lskj/ls_award.html>

“开奖数据”页面可同步最新数据或导入 UTF-8 JSON / CSV。文件导入默认与现有数据合并；相同期号的不同结果会拒绝导入，不覆盖原数据。用户导入数据会单独标注来源，不会自动获得官方认证。

JSON 每行结构：`issue`（7 位期号）、`date`（YYYY-MM-DD）、`red`（6 个不同的 1—33 整数数组）、`blue`（1—16 整数）。CSV 表头可用 `issue,date,red,blue`，红球字段用空格分隔。也支持中文表头 `期号,开奖日期,红球,蓝球`。

命令行同步：

```powershell
node scripts/sync.mjs
```

## 模型与训练必要性

基础模型选择 **贝叶斯平滑概率模型**。它把历史频次向均匀先验适度拉回，减少样本中的偶然起伏；参数少、运算快、每一步可解释，适合先检验是否存在信息。

| 模型 | 工作方式 | 训练是否必要 |
| --- | --- | --- |
| 均匀随机基线 | 所有合法完整组合等概率 | 无需训练，是必须保留的参照 |
| 贝叶斯平滑 | 全历史频次与均匀先验结合 | 默认参数可直接拟合；可选训练选择平滑强度 |
| 近期衰减平滑 | 在平滑模型基础上降低较旧开奖权重 | 默认参数可直接拟合；可选训练选择平滑强度和半衰期 |

这里的训练是**时间顺序验证与参数选择**，不是反复跑很多轮就会越来越准。数据和引擎版本都未改变时，重复点击训练会复用已有结果。

训练至少需要 200 期数据。按时间划分约 60% 早期区间、20% 参数验证区间、20% 留出测试区间（后两区间各至少 60 期）。先在验证区间选择参数和候选模型，再锁定参数检查测试区间。每一期只使用此前已知的数据；测试区间不会用于重新挑选超参数。最终可用模型才用全部已知数据重新拟合。

报告使用完整开奖的负对数似然，数值越小表示给实际结果分配的概率越合理；同时显示与均匀基线的逐期差值及分块重采样诊断区间。测试未支持候选模型时，报告保留均匀基线。诊断不是未来效果的证明，也不直接证明头奖命中率提高。反复查看同一测试集不算新的独立证据。

### 概率如何计算

红球不是 33 次互相独立的选择：每期必须恰好包含 6 个。模型先从平滑频次得到权重，再对所有含 6 个号码的集合使用 `P(S) ∝ ∏wᵢ` 的联合分布，通过动态规划精确归一化、计算边际和抽样。蓝球使用 16 类的平滑概率。

- 红球显示的是“这个号码出现在本期 6 个红球中”的模型估计概率，33 项合计为 **6**。
- 蓝球显示的是“这个号码被开出”的模型估计概率，16 项合计为 **1**。
- 它们是基于模型假设的估计，不能当作已知的真实开奖概率。

## 开奖前预测

1. 在“开奖数据”同步并核对最新一期。
2. 选择模型；如已经训练，可选择使用训练选出的参数。
3. 设置红球候选数 **6—33**、蓝球候选数 **1—16**、完整号码组数 **1—100**。
4. 核对系统显示的下一期与预计时间，点击“保存本次预测”。

候选池按模型的边际概率排序选取，概率并列时使用随机种子打散。完整号码在候选池中按模型权重抽样，组间去重。候选池容量不足时拒绝生成。相同数据、模型、参数、数量和种子可以复现结果。

例如 8 个红球候选、2 个蓝球候选，可以组成 `C(8,6) × 2 = 56` 种完整组合；生成 5 组只保存其中 5 组。页面分别显示候选池全部展开和实际保存组数的公平开奖理论覆盖率。单组理论头奖概率为 `1 / 17,721,088`，扩大候选池本身不等于已经覆盖全部组合。

### 留档边界

- 正式保存前，在线查询中国福彩最新一期；若与本地最新数据不一致或网络核验失败，拒绝保存，需先同步或重试。离线仍能预览概率、训练和查看已有记录。
- 本版按常规周二、四、日及北京时间 **21:15** 推算下一期并封存，不允许把截止时间或目标日期向后挪动。**遇休市、临时调整或提前开奖，应停止创建该期记录，先核对官方公告；本版没有完整休市日历。** 推算时间并非来自官方未来开奖日历。
- 每次保存新文件，保留模型及参数、随机种子、数据截止期、数据快照、官方最新期核验、创建时间和校验码；页面没有修改旧记录的接口。
- 本地时间来自运行电脑，校验码可检测普通文件修改，**不等同于第三方可信时间戳或公证**。
- 数据更新后，已保存记录自动核对同一期实际红蓝命中数，并用当时封存的模型计算实际开奖的负对数似然及相对基线的差值，原始号码不变。不会使用后来训练的模型回算旧预测。日期不匹配或创建时间不早于封存截止的记录不会计入前瞻验证。
- 记录用于研究与模拟，不包含购票、资金操作或收益承诺。

## 文件位置

| 文件或目录 | 内容 |
| --- | --- |
| `data/draws.json` | 原子保存的开奖数据与来源快照 |
| `data/provenance.json` | 来源信息的可读镜像 |
| `data/raw/` | 同步或导入时的原始响应 |
| `data/models/` | 训练结果、选参和完整测试报告 |
| `data/predictions/` | 每次预测的独立原始 JSON |
| `data/snapshots/` | 预测当时使用的数据快照 |
| `src/data.mjs` | 官方数据适配、校验与合并 |
| `src/models.mjs` | 联合概率、采样与时序验证 |
| `src/workspace.mjs` | 截止时间、留档与开奖核对 |
| `server.mjs` | 本机 HTTP 服务与接口 |
| `public/` | 本地中文操作页面 |

模型和预测记录默认不进入 Git。备份研究记录时，请备份整个 `data` 目录。
